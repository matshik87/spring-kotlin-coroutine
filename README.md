## Bronco

initial idea.
sth alike polish allegro
a module with e-commerce functionality
a module with sth alike payment module(more like a bank)
when a user is created on e-commerce and account at payment module is created.
if user was already created then it's reused

e-commerce

- add/delete/modify user
- add/delete/modify products
- update stock
- login/logout
- cart management

payment module

- create/modify/close an account
- update balance
- money transfers
- pay for purchase
- schedule operations

for sure:
 - kotlin
 - kafka
 - postgresql
 - coroutines
